# NEXUS DESIGN SYSTEM

## 1. Typography
- **Primary:** Geist Sans (Headlines, Body, UI Text).
- **Secondary:** Geist Mono (Metadata, System States, Timestamps, Labels).
- **Tertiary:** Serif (Evidence Quotes, Document Extracts).
- **Headlines:** tracking-tighter, font-medium, text-zinc-50.
- **Labels:** uppercase, tracking-[0.2em], text-[10px] to text-xs, text-zinc-500.

## 2. Color Palette
- **Background Base:** #050505
- **Surface Elevation 1:** #0A0A0A
- **Surface Elevation 2:** bg-white/5
- **Structural Borders:** border-white/5 to border-white/10
- **Primary Text:** text-zinc-50
- **Secondary Text:** text-zinc-400
- **Tertiary Text:** text-zinc-600
- **Accent/Brand:** text-indigo-400, bg-indigo-500

## 3. Spacing & Grid
- Macro-whitespace for editorial cinematic feel.
- Structural 1px lines (gap-px bg-white/10) for dividing content rather than padded rounded cards.
- Technical crosshairs and grid overlays (g-[radial-gradient]) to denote interactive or processing zones.

## 4. Components
- **Buttons:** Sharp or subtly rounded (2px to 4px), not fully pill-shaped unless explicitly acting as a search bar constraint. No heavy dropshadows.
- **Inputs:** Stark, border-bottom focused, or extremely minimal containers. 
- **Documents:** Rendered as technical objects (ID, Status, Metadata) not as fluffy icons.
